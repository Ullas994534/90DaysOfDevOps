Part 2: Scenario-Based Practice
SOLVED EXAMPLE: Check if a Service is Running
Scenario
Check whether the nginx service is running.

Step-by-step Solution
Step 1: Check service status

bash
Copy code
systemctl status nginx
Confirms whether the service is running, stopped, or failed.

Step 2: List all services if not found

bash
Copy code
systemctl list-units --type=service
Step 3: Check if service is enabled on boot

bash
Copy code
systemctl is-enabled nginx
Step 4: Check logs

bash
Copy code
journalctl -u nginx -n 50
journalctl -u nginx -f
Scenario 1: Service Not Starting
Problem
A web application service called myapp failed to start after a server reboot.

Diagnostic Steps
Step 1: Check service status

bash
Copy code
systemctl status myapp
Step 2: View service logs

bash
Copy code
journalctl -u myapp -n 50
Step 3: Check if service exists

bash
Copy code
systemctl list-unit-files | grep myapp
Step 4: Verify service configuration

bash
Copy code
cat /etc/systemd/system/myapp.service
systemctl daemon-reload
Why this flow?
Status → Logs → Configuration → Reload systemd.

Scenario 4: File Permissions Issue
Problem
Script /home/user/backup.sh is not executing.

Error:

bash
Copy code
./backup.sh
Permission denied
Step-by-step Solution
Step 1: Check current permissions

bash
Copy code
ls -l /home/user/backup.sh
Example: -rw-r--r-- (no execute permission)

Step 2: Add execute permission

bash
Copy code
chmod +x /home/user/backup.sh
Step 3: Verify permissions

bash
Copy code
ls -l /home/user/backup.sh
Expected: -rwxr-xr-x

Step 4: Run the script

bash
Copy code
./backup.sh
