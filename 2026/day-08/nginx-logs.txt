# Day 08 – Cloud Server Setup: Docker, Nginx & Web Deployment

## Task Overview

The goal of Day 08 was to deploy a real web server on the cloud and practice practical server management tasks that are commonly performed in real-world DevOps and production environments.

This included launching a cloud instance, connecting via SSH, installing and configuring Nginx, managing security groups, extracting logs, and verifying public web access.

---

## Prerequisites

* AWS account (Free Tier)
* Basic understanding of Linux commands (Days 1–7)
* SSH client (Linux/Mac terminal)

---

## Part 1: Launch Cloud Instance & SSH Access

### Step 1: Create a Cloud Instance

* Launched an **Ubuntu EC2 instance** using AWS Free Tier
* Created and downloaded an SSH key pair (`.pem` file)
* Configured security group to allow:

  * SSH (port 22)
  * HTTP (port 80)

### Step 2: Connect via SSH

```bash
ssh -i your-key.pem ubuntu@<your-instance-public-ip>
```

📸 Screenshot: `./images/ssh-connection.png`

---

## Part 2: Install Docker & Nginx

### Step 1: Update System

```bash
sudo apt update && sudo apt upgrade -y
```

### Step 2: Install Docker

```bash
sudo apt install docker.io -y
sudo systemctl start docker
sudo systemctl enable docker
```

### Step 3: Install Nginx

```bash
sudo apt install nginx -y
sudo systemctl start nginx
sudo systemctl enable nginx
```

### Verify Nginx is Running

```bash
systemctl status nginx
```

---

## Part 3: Security Group Configuration

* Verified inbound rules allow HTTP traffic on port 80
* Tested web access from browser:

```text
http://<your-instance-public-ip>
```

✅ Nginx welcome page displayed successfully

📸 Screenshot: `./images/nginx-webpage.png`

---

## Part 4: Extract Nginx Logs

### Step 1: View Nginx Logs

```bash
sudo cat /var/log/nginx/access.log
```

### Step 2: Save Logs to a File

```bash
sudo cat /var/log/nginx/access.log > ~/nginx-logs.txt
```

### Step 3: Download Log File to Local Machine

**For AWS:**

```bash
scp -i your-key.pem ubuntu@<your-instance-public-ip>:~/nginx-logs.txt .
```
