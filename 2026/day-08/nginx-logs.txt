# Day 08 – Cloud Server Setup: Nginx & Web Deployment

## 🎯 Task
Today's goal is to deploy a real web server on the cloud and learn practical server management.

This task was completed with **real hands-on practice** on a live cloud server.

---

## 🚀 Objectives

- Launch a cloud instance (AWS EC2)
- Connect to the server using SSH
- Install and run Nginx
- Configure security groups for web access (Port 80)
- Extract and save Nginx logs
- Verify the webpage is accessible from the internet

This is real DevOps work – exactly what is done in production environments.

### Step 2: Connect via SSH

Part 2: Install Nginx Web Server
Step 1: Update System
sudo apt update

Step 2: Install Nginx
sudo apt install nginx -y

Step 3: Start and Enable Nginx
sudo systemctl start nginx
sudo systemctl enable nginx


Verify Nginx status:

systemctl status nginx

Part 3: Security Group Configuration

Part 4: Extract Nginx Logs
Step 1: View Nginx Logs
sudo cat /var/log/nginx/access.log

Step 2: Save Logs to File
sudo cp /var/log/nginx/access.log ~/nginx-logs.txt

Step 3: Download Log File to Local Machine
scp -i my-key.pem ubuntu@<EC2-PUBLIC-IP>:~/nginx-logs.txt .
